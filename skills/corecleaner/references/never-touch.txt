# CoreCleaner never-touch list. Parsed ONLY by corecleaner_lib/safety.py; the agent may read it, never edit it.
# teto: isento (registry; one rule per line, length is the data). Any edit needs two reviewers (last wall).
#
# Grammar: UTF-8, LF. '#' starts a comment only at line start. Blank lines ignored.
#   [all] [macos] [linux] [windows]   section header; [all] always applies, the OS section adds to it.
#   <mode> <pattern>                  mode, whitespace, then the rest of the line (spaces allowed in pattern).
# Modes (A = candidate after safety.normalize(); P = pattern after expansion + normalize()):
#   tree  P   refuse A when A == P, A is under P, or A is a PARENT of P.
#   node  P   refuse A when A == P or A is a PARENT of P; descendants stay allowed (tidy inside, never the folder).
#   name  N   refuse A when ANY path component of A matches N (fnmatch on one component, no '/').
# Pattern syntax:
#   ~                   HOME (USERPROFILE on Windows).
#   $VAR ${VAR} %VAR%   environment variable, tree/node only and only at the very start of the pattern
#                       ('$' or '%' anywhere else, and every `name` pattern, is literal); unset = rule skipped, never an error.
#   * ? [seq]           fnmatch inside ONE component, never across '/'.
#   <root>              every filesystem root and drive root (/, C:/, D:/); node mode only.
#   '/' is the only separator, Windows included. Matching: realpath, NFC, casefold on case-insensitive
#   filesystems, Windows 8.3 names and the \\?\ prefix resolved by safety.normalize().
# Code, not this file, handles: cloud placeholders, live processes, dirty repos, symlink targets.
# Agent history and caches (~/.claude/projects, file-history, ~/.codex/sessions, worktrees) are NOT listed: they are the job.
